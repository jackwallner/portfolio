# Hockey Edge changelog

> Every Hockey Edge update, newest first.

Web page: https://jackwallner.com/ios/hockey/changelog.html

## Version 1.0.5 (November 23, 2026)

Behind-the-scenes improvements and fixes to keep Hockey Edge running smoothly. Thank you for being here.

## Version 1.0.4 (November 18, 2026)

Now on iPad, with a layout designed for the larger screen.

## Version 1.0.3 (November 9, 2026)

Game pages opened before puck drop now show the live score once the game starts. Trends keeps its loading spinner while recent form loads, and moves off a locked season if Pro ends mid-session.

## Version 1.0.2 (November 3, 2026)

Player search on the leaderboards now finds skaters and goalies at every position, not only the tab you have open.

## Version 1.0.1 (October 22, 2026)

Share any player's percentile board as an image, right from their profile.
Leaderboards, search and season switching are much faster, especially for past seasons.
Clearer pricing on the upgrade screen.

## Version 1.0 (October 14, 2026)

First release on the App Store.
