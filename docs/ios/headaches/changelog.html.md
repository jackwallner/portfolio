## Version 1.4.4 (June 26, 2026)

This update makes Headache Pro’s insight engine smarter and more reliable so you can trust the patterns you see.

- 15 new pattern detectors, including combined-trigger detection that can highlight co-occurrences like pressure drops plus poor sleep
- Tighter thresholds for surfacing insights to reduce false positives and focus on patterns that actually hold up in your data
- A more polished history view and smoother onboarding to make it easier to review past headaches and get set up
- General performance and stability improvements to keep logging and analysis fast and dependable

## Version 1.1.0 (April 24, 2026)

- Headache events no longer show a red "Failed" badge when Health permissions are already granted
- More reliable step count, sleep, heart rate, and workout context capture
- Smoother onboarding, one less permission prompt mid-log

## Version 1.1 (April 21, 2026)

- Apple Watch logging is faster and no longer gets stuck on "Sending…", added a send timeout, fixed a cold-start race, and "Connecting to iPhone…" now clears once paired.
- Barometric-pressure trend captures correctly around midnight and uses sea-level pressure for consistent comparisons.
- "Last night's sleep" uses a fixed overnight window, so afternoon events no longer include daytime naps.
- Home screen no longer duplicates the newest event in "Recent Logs".
- Widget "Logged" confirmation is more reliable.
- CSV export: new weekday_index column, RFC 4180 line endings, stable weekday names across locales.
- Plenty of stability fixes around location, networking, and sharing.
